# Настройка и Запуск Проекта

>  **ВАЖНО:** «Из коробки» проект у вас сразу **не запустится**! Перед запуском необходимо убедиться, что сервис **Ollama** работает в фоновом режиме, а в коде указана модель, установленная на вашем ПК.

---

## Предварительные требования

1. Установите и запустите **[Ollama](https://ollama.com/)**.
2. Убедитесь, что Ollama запущен и работает в фоновом режиме (по умолчанию порт `11434`).
3. Загрузите любую желаемую модель через терминал (если ещё не скачали):

   ollama pull llama3

   > Посмотреть список всех уже скачанных у вас моделей можно командой: `ollama list`

---

## Настройка `main.py` перед запуском

1. Откройте файл `main.py`.
2. Перейдите на **23-ю строчку**.
3. Впишите название **любой модели**, которая загружена у вас в Ollama:

   MODEL_NAME = "llama3"  # <-- Укажите здесь имя вашей локальной модели

---
